# Portal Workflows

## Customer Journey

### 1. Discover services

- Select a saved home
- View location-aware service availability
- Ask for AI recommendation from problem text

### 2. Create a booking

- Open `Booking`
- Choose address, service, and booking mode
- Enter problem details and urgency
- Choose provider
- Confirm booking

Result:

- booking is saved locally
- booking appears in history/tracking
- provider portal can now act on it

### 3. Communicate and pay

- Open `Providers` to send a booking message
- Open `Payments` to pay invoice or request dispute/refund
- Open `Support` to create a ticket linked to the booking

### 4. Review completed work

- After provider completion/invoice flow, customer can submit a review

## Provider Journey

### 1. See assigned work

- Log in as provider
- Open `Jobs`
- Inbox is populated from customer bookings assigned to that provider id

### 2. Act on jobs

- `Accept` moves the booking into active/in-progress style state
- `Decline` marks it cancelled
- `Send quote` updates quote details
- `Send` in invoice panel completes invoice workflow

### 3. Communicate

- Use `Customer chat` or schedule message areas to write into booking threads

## Admin Journey

### 1. Control service rollout

- Open `Service controls`
- Select a market address
- Review service rows by status/risk
- Enable reviewed services or change rollout state

### 2. Review providers

- Open `Providers`
- Approve or suspend providers from the queue

### 3. Audit actions

- Open `Support ops`
- Review audit log entries from admin activity

## Support Journey

### 1. Review ticket queue

- Tickets created by customers appear in support views
- Support can move tickets through statuses

### 2. Handle disputes and escalations

- Use `Disputes` and `Escalations` groups for simplified ticket lifecycle actions

### 3. Send replies

- Use `Messages` to respond into ticket threads

## Regional Journey

### 1. Review market demand

- Demand panels show derived values from bookings, tickets, and local feature data

### 2. Monitor supply and outcomes

- Supply score, completion count, and cancellation rate update from booking activity

### 3. Evaluate market readiness

- Launch/global/markets panels remain a mix of derived and presentational content for now
